# T4L ProteinMC AV-Restrained Example

This directory is a loadable ChiSurf project fixture for running a ProteinMC model with the T4L structure and FPS JSON AV restraints.

- Project directory: `examples/projects/t4l_proteinmc/`
- Structure: `data/3GUN-processed.pdb`
- FPS restraints: `data/fret.fps.json`
- Default output trajectory: `data/t4l_docking.rmf3`
- Settings: `proteinmc_settings.json`

Loading this project restores a `ProteinMC` model widget with the T4L structure, FPS JSON restraint file, output RMF path, and sampling settings prefilled.
