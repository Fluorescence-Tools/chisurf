# T4L Chimol Trajectory Example

This directory is a loadable ChiSurf project fixture for opening the T4L RMF trajectory in Chimol.

- Project directory: `examples/projects/t4l_chimol/`
- Structure: `data/3GUN-processed.pdb`
- FPS restraints: `data/fret.fps.json`
- RMF trajectory: `data/t4l_docking.rmf3`
- Supporting files: `data/3GUN.pdb`, `data/topology.dat`, `data/3GUN.fasta`, `data/3GUN.dssp`
- ProteinMC settings: `proteinmc_settings.json`

Load the project by selecting this directory. The native project loader expects a directory containing `project.json`.
