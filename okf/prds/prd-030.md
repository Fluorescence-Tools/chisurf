# Summary
Defines, formally and with strong typing, the on-disk payload format for every
scientific result kind MFDB stores (FCS correlations, spectra, TTTR references,
TCSPC decays, burst tables and selections, anisotropy curves, PDA histograms,
and more). It replaces ad-hoc, lossy JSON serialization with a single
msgpack-based, schema-validated codec module exposing `encode_payload`,
`decode_payload`, and `get_payload_schema`, using a self-describing envelope so
decoding needs no external hint. Today `data_format` is a free-text label that
drives no deserialization, DataFrames and dicts are serialized losslessly-poorly,
and there is no formal schema per kind; this codec becomes the sole
(de)serialization choke point.

# Status
Done. Foundational layer (named with the `0X0` convention like the ORM mapping)
that is a hard prerequisite for the result registry.
