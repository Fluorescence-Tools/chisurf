# Reference

`overhaul/` holds numbered PRD design notes (`PRD-NN-*.md`) that drive current
work. Consult the relevant PRD before large changes in its area — e.g.
PRD-40 (model/UI split feeding [AutoForm](/subsystems/gui-autoform.md)),
PRD-43/44 (history as an [MFDB](/architecture/mfdb.md) projection), and
PRD-48 (provider-agnostic ELN gateway).

Complementary clean-architecture targets live in this bundle's
[specs group](/specs/index.md), with the current-state gap captured in the
[assessment backlog](/specs/assessment.md).
