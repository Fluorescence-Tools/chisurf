Fit Plots
---------

Fits display (depending on the model) different plots that can be selected within the fit window in the MDI (:strong:`Fig.18`). Plot settings are displayed in a separate dock window. The displayed settings depend on the currently selected plot.

.. image:: _images/image_rId25.png
  :align: center

:strong:`Fig.18 Plots in fit windows.` The fit windows in the multiple document interface display different plots. The plots created for a certain model can be selected on the of a fit window (left, highlighted in yellow). The settings of the currently selected plot of the active fit window are displayed in the 'Plot settings' dock (right).

Most fit models display line plots of the corresponding data and model function along with weighted residuals and auto correlation functions computed of the weighted residuals (:strong:`Fig.18`, left). The settings of a plot can be used to modify the plot (:strong:`Fig.18`, right).
