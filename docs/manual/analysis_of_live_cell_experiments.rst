Analysis of live cell experiments
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Again, also here, we assume that you have already correlated your data using the software of your system or any of the software mentioned in the beginning.

We will show you first how to add your own fit models to ChiSurf and next analyze first the measurements of the singly labeled constructs (β2AR-eGFP-IL3 and NT-SNAP-β2AR) before switching to the double-labeled NT-SNAP-β2AR-eGFP-IL3 sample.
