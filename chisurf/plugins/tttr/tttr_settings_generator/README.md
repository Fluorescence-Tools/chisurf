# TTTR Settings Generator

This plugin provides a graphical interface for creating TTTR settings JSON files containing LUTs (Look-Up Tables) and time shifts per channel for TTTR (Time-Tagged Time-Resolved) data correction.

## Features

- Load TTTR files (.spc, .ht3, .ptu, .phu, .photonhdf5)
- Select TTTR reading routine (Auto, PTU, HT3, SPC formats, etc.)
- Load and assign LUT files (.npy, .npz, .txt) to channels
- Set time shifts per channel
- Apply corrections and visualize microtime histograms
- Generate and save settings.tttr.json files with LUTs and shifts

## What are LUTs?

LUTs (Look-Up Tables) are correction arrays used to compensate for instrument response functions (IRF) in TTTR data. Each LUT contains a series of correction values that map microtime bins to their corrected positions, accounting for:

- Instrument timing jitter
- Detector response characteristics
- Electronic delays in the measurement setup

A LUT is essentially an array where each element represents the cumulative correction factor for that microtime bin. For example, if bin 100 should actually correspond to bin 102 after correction, the LUT value at index 100 would be 2.0 (indicating a +2 bin shift).

## How to Compute LUTs

LUTs can be computed using the **TTTR:Compute Microtime LUT** plugin, which analyzes TTTR data from known reference samples (such as prompt fluorescence or scatter measurements) to determine the instrument response function.

To compute a LUT:

1. Launch the "TTTR:Compute Microtime LUT" plugin from ChiSurf's Plugins menu
2. Load TTTR files containing your reference measurement
3. Select the channel to analyze
4. Configure the analysis parameters (time range, binning, etc.)
5. Run the computation to generate the LUT array
6. Save the LUT as a .npy, .npz, or .txt file for use in this plugin

The computed LUT will be a 1D array with one correction value per microtime bin in your TTTR data.

## Usage

1. Launch the plugin from ChiSurf's Plugins menu under "TTTR:Settings Generator"
2. Select TTTR reading routine if needed (default is Auto)
3. Drag and drop TTTR files or use "Add files" button
4. Load LUT files (drag and drop onto LUT list or use "Load LUT" button)
5. Check/uncheck channels in the channel list to show/hide them in the plot
6. Select a channel to adjust its time shift
7. Assign LUTs to selected channel or all channels
8. Preview the JSON settings
9. Load existing settings from a JSON file
10. Save the settings.tttr.json file

## Loading Existing Settings

You can load previously saved settings using the "Load JSON" button. This will:

- Apply the saved reading routine
- Restore channel LUT assignments
- Restore channel time shifts
- Update the display with the loaded corrections

Loading settings does not require TTTR data to be loaded first - you can load settings and then load your data, or load data first and then apply settings.

## Output Format

The generated settings.tttr.json contains:

```json
{
  "description": "TTTR microtime correction settings",
  "version": "1.0",
  "reading_routine": null,
  "channel_luts": {
    "0": [0.0, 0.1, 0.2, ...],
    "1": [0.0, 0.1, 0.2, ...]
  },
  "channel_shifts": {
    "0": 5,
    "1": -2
  },
  "metadata": {
    "created": "2025-11-08T12:28:00",
    "used_channels": [0, 1],
    "notes": "Generated by TTTR Settings Generator plugin"
  }
}
```

Where `reading_routine` is the container type used for reading TTTR files (null for auto-detection, or integer values for specific formats).
